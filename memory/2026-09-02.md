# 2026-09-02 — Desafio Vita: player homebrew + capas

## Contexto
Objetivo: portar o tocador Stylus (PC + Android) para PS Vita como homebrew
(desafio). Usuário priorizou definição da entrega mínima: **"um VPK que abre
e toca música local"**, com biblioteca local decente (capas, álbuns
ordenados, playlists depois) e Qobuz como fonte de streaming (não cliente
Qobuz nativo). UI segue a lei do vinil (§5.5): âmbar no quase-preto, nunca
realismo.

## O que pegou (lições técnicas) — NÃO DESFAZER às cegas
- **`rel_dir` sem barra à esquerda**: em `scan_dir`, `child_rel` começava com
  '/' (base "" + "/" + nome). Prefixava a chave do álbum. Fix: se rel vazio,
  sem '/'. Sintoma de quem vê chaves tipo `/Artist/Album`.
- **Agregação por chave ≠ nome exibido**: `find_album` checava `Album.album`
  (último segmento) contra a chave completa → nunca batia → todo mp3 virava
  álbum (3728 em vez de ~387!). Fix: campo `key[MAX_PATH_LEN]` (caminho do
  dir do álbum) para agregar; `album` é só o último segmento p/ exibir.
- **`album_load_cover` tinha o loop invertido**: `alb->ntracks - i < 8` para
  um álbum grande → sempre falso → nenhuma faixa testada → 0 capas. Sintoma:
  álbum inteiro sem capa mesmo com APIC em todas as faixas. Fix: `i < 8`.
- **`mpg123_init()`/`exit()` a cada `tags_read`** corrompia o estado em loop
  (rápido; chamadas em massa). Fix: init uma vez (`tags_init`/`tags_exit`).
- **`vita2d.h` NÃO tem círculo nem `vita2d_ext.h`**; círculos à mão
  (scanline: `vita2d_draw_rectangle` linha a linha, `sqrtf`).
- **mpg123 1.33 ID3 já é UTF-8**; faixa=nº vem em `text[]` (id "TRCK"), não
  em `v2->track`; capa em `v2->picture[]`, tipo `mpg123_id3_pic_front_cover`,
  habilitar com `MPG123_PICTURE`.
- **dirent do Vita não tem `d_type`** → usar `stat()`/`S_ISDIR`/`S_ISREG`.

## Capas (importante p/ re-sincronizar o cartão)
- A conversão p/ MP3 NÃO embute APIC: na fonte 3/405 álbuns tinham capa.
- `embed_covers.sh` injeta `cover.jpg` (lossless `~/Músicas/Songs`) nos MP3s
  de `~/staging-vita/vita-mp3/` por nome de pasta, a 500px JPEG, `-c:a copy`
  + `-c:v mjpeg -q:v 4`, `attached_pic`. **`-f mp3` OBRIGATÓRIO** no ffmpeg
  quando o arquivo de saída é `*.tmp` sem extensão (senão "Unable to choose
  an output format").
- Resultado: 3242 faixas embedadas; 339/405 álbuns com capa. Os faltantes
  são bootlegs (Radiohead/Strokes) sem cover.jpg na fonte — não vale caçar.
- Player lê capa via APIC (npm do primeiro mp3 com front cover, até 8 faixas).

## Validação host (sem VitaSDK)
`gcc library.c tags.c + libmpg123 do sistema` → funciona; é a forma de testar
o núcleo (agregação, ordenação, capas) no PC. `mpg123` host é a mesma versão
1.33.7 do Vita → API ID3 idêntica. Ferramentas em `/tmp/opencode/`
(vita_host_test, cover_scan, cover_check, dbg_cover, probe).
